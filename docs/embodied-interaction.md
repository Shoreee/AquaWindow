# 具身协作的七种操作

核心保留 2026-10-28 17:22 左右的小型三层流动膜面，不加球壳。抽出的条带来自同一膜面，保留材料缺损与恢复反馈。详见 [视觉恢复记录](visual-1722-reference.md)。

所有动作与实际窗口布局共享逐帧时钟，使用起止速度、加速度连续的缓动；不是布局先跳变、再补播特效。移位允许和揭示等操作并行，锚附不占用布局动作时段。

| 原语 | 身体与窗口的共同变化 |
| --- | --- |
| 锚附 Anchor | 保留协作入口，不作为独立布局表演 |
| 中央／边缘揭示 Peel | 中央从上层空白区域镂空，必要时配合移位对准下层重要内容；边缘从上角蚕食。两者均裁切真实窗口，缺口透出下层与透明光流，不生成文字面板。波动边缘可拖动闭合，支持撤回 |
| 让界 Yield | 窗口一条实际边界受牵引，对边与垂直方向不变 |
| 包裹 Encapsulate | 窗口逐个排队，先包覆，再沿弧线加速滑向胶囊，末端颈缩、汇入；等待者保持原位，已汇入者不再堆叠 |
| 分生 Branch | 包覆的窗口从边缘颈缩出结果子窗口，原内容与结果在合成层内容形变中渐变，没有两个独立虫体 |
| 汇合 Merge | 子窗口以同一工作进度回到主体并收束，参与窗口保留共同节奏的流动边沿 |
| 渗层 Permeate | 窗口层深实际改变，边缘和向内扩展的折射波纹表达潜入水面 |

移位牵引最多两条相邻的前进边。窗口自身使用轻量矢量轮廓裁切，材质在同一轮廓下延伸；张力场平滑扩散到相邻边并略微越过角落。没有另画一条白色搬运带；轮廓与内容形变在交接前逐渐归零。分裂与汇合结合边界颈缩和低频内容形变，避免把文字打碎成噪点，也避免对整扇窗口及其阴影执行逐像素滤镜。旧揭示层在下一动作的准备阶段先收拢，防止方案切换时突然消失。

指定对象的选择先用约 1 秒在 Z 轴轨道中前后游动，随机落到窗口边缘，再用约 0.8 秒贴边环绕。条带离开后，明亮的流动边沿持续表达选中。再次点击取消时，能量从边沿沿弧线回收到核心；飞行中取消则连续逆转尚未抵达的那段运动。减少背景压暗，提示保持可读。

包裹队列每项错开 1.25 秒，实际搬运区间 1.15 秒，轨迹中段速度最高；胶囊随每次汇入轻微变形并显示队列计数。窗口自身的内容和阅读位置保存在会话快照中，可完整恢复。退出包裹只收束边缘，禁止将边缘距离场切换成整面白色填充。

普通移位、分生、汇合不自动打开结果面板；只有明确揭示或点击锚点时展示。长按空格孵化核心后，展示中央揭示、边缘揭示、让界、包裹、分生、汇合、渗层七个独立候选；不再自动轮播。左右箭头可中途切换，松开立即接受当前方案并连续完成其动画，Esc 或撤回按钮撤回。长按空格的孵化阶段可点击窗口增减对象，每次点选重置等待时间；未点选则超时全选。爆开后才用左右键切换候选。DeepSeek 默认关闭，本地视觉测试不请求模型。

验证入口：`pnpm test`、`pnpm test:embodied`、`pnpm test:fluid`、`pnpm test:e2e`。回归检查真实窗口位移、单项队列、子窗口裂合与来源保留、取消后的材料回收、持续选中提示、包裹无白膜、减少动态效果和完整撤回。

数值约束：有符号平方直接相乘，避免 GLSL 负底数 `pow` 的未定义行为；预乘透明度必须满足 RGB 不超过 alpha，低能量像素平滑归零。窗口的几何从 `.aw-shell` 实际显示边界读取，包含层深缩放和位移。

## 胶囊与材料连续性

让界只在实际受操作的边产生朝移动方向的非对称白色波动，对侧保持光边；轮廓与光边使用同一组几何点。连续按住空格切换同一对象时沿用已建立的材料连接，提交或撤回后条带回收进核心。胶囊的移动、缩放与释放也会触发同一核心收发过程。

胶囊由实际页面预览分段融合，加入页面时单调增大；三个页面默认约 242×88。悬停页面会模糊内部混合预览并居中显示该页标题，移动和缩放期间完全隐藏页面预览。胶囊支持原生拖动及八方向缩放，超出容量阈值会自动破裂、错峰释放页面；Option 拖动某一页会从该段位置拉出页面，并平滑缩小余下容器。原宿主页可独立拖出，容器会更换身份以保留其余页面。快速松手后仍会完成脱离动画。各手势只产生一个撤回记录，保留页面内容、身份和阅读位置。

验证：`pnpm test:capsule` 覆盖悬停、隐藏预览、移动缩放、单页拖出、宿主页身份分离、缩小、拉大破裂和一步撤回；`pnpm test:e2e` 覆盖七候选、左右键中断、松开接受及 Esc／按钮撤回。

揭示回归：`node scripts/reveal-e2e.mjs` 覆盖孵化点选、超时全选、真实内容镂空、边缘揭示、拖动闭合和撤回。开口切换先收旧再开新，闭合后停止轮廓动画。

## 人与 Agent 共用边界操作

每次形变记录左、右、上、下四边的实际位移。单拉上边属于让界；上边与任意其他边一起移动，或整窗平移，则属于包覆搬运。下角拖动同时牵动两条相邻边。受力侧仅朝实际位移方向波动，静止边只保留微光；矢量材质、平滑轮廓与色散光边采用相同几何，光边放在裁切层外，避免被窗口自身截掉。揭示状态不再禁用外沿反馈。

普通手动移动、八向缩放、贴边吸附、最大化与恢复接入同一运动契约；搬运先沿边包覆，实际窗口略有惯性地追随手势，松手后收束，Esc 可完整撤回一次。拖动不重绘文档树。中央镂空加强了轮廓波动、白色光边及少量冷暖色散，不填充白色蒙版。统一降低环境压暗，保留清晰的操作状态提示。

专项回归：`node scripts/boundary-e2e.mjs`；渲染回归：`pnpm test:render`、`pnpm test:fluid`。

## 柔白膜边与搬运蔓延（统一修订）

让界和两种揭示使用同一个 `livingWave` 场和 `LivingRim` 材质：宽缓且单侧的白色流动，冷暖色散仅作为柔光，取消虚线、硬描边和等粗的彩色双线。中央镂空是带波动的圆角矩形；边缘揭示只撕开最上层操作窗口，只照亮切口，下层页面没有选中描边或 GPU 蚕食印记，空隙内光流降为轻提示。

移动使用独立的包覆过程：同一材质从一角蔓延到窗口表面，包覆到位后带动真实窗口，到位再退去释放。手动搬运在包覆初段保持原位，指针目标持续缓存，随后追随并在松手后完成退膜；移动不再套用让界的波浪轮廓。这里的“独立”指行为语义不同，材质和流场仍共用。

揭示、让界、裂合、移位与渗层主要动作提速约 15%–20%；胶囊队列从每项 1.25 秒错开、1.15 秒搬运改为 1.08 秒错开、0.98 秒搬运，仍逐个收纳。选择窗口的等待时间保持不变。

手动包覆起点固定为按下时在窗口内的相对坐标，随着窗口移动保持附着；自动布局保留角落起点。手动包覆增加到约半秒再跟随，自动搬运用前 42% 工作阶段完成包覆，避免蔓延过快。
