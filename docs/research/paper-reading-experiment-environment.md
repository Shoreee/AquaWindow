更新日期：2026-10-31  
对象：AquaWindow 虚拟桌面中的「涡虫能量体」窗口交互  
状态：方案整理，交互形式与实验条件待预实验验证

## 1. 本阶段目标与边界

本阶段研究的是：在论文阅读中，用户能否理解、使用并找回由柔性窗口承载的不同交互形式。实验任务应让用户真实地阅读、对照、引用和返回材料，而非单纯展示动画。

- **暂不研究 Agent 功能。** 不调用 Agent，不呈现自动提案、自动排布或语义推理结果；Figma 任务表的「Agent 的具体功能实现」只作为任务情境线索，不作为本阶段功能清单。
- **空格键暂时不承担 Agent 唤起功能。** 当前原型的按住 Space 唤起 Agent 与本阶段目标冲突。Figma 纵深方案中的「按 Space 暂时透视」也暂缓使用同一按键；若保留透视，应另设明确入口并单独验证，避免操作混淆。
- **保留视觉与运动语言。** “The interface makes these changes tangible through a shared language of soft membranes, flowing white material, and restrained optical dispersion.” 新增交互也应以柔软膜状边界、流动白色材质和克制的光学色散表现作用、过渡与结束状态。视觉效果需服务于窗口关系和操作反馈，不遮蔽论文文字。
- **本文件先确定实验环境准备方向。** 具体交互集合、对照条件、任务顺序和量化指标将在预实验后调整。

## 4. 候选交互与论文阅读适配

这里的交互是**供比较的候选形式**，不要求一次实验全部启用。每项先有可解释的触发、可见的结果和可逆的退出，再进入预实验。

| 候选形式 | 适合的阅读动作 | 设计约束与待验证点 |
| --- | --- | --- |
| 掀角与钉住 | 短暂查看被上层论文挡住的段落或图示 | 松手恢复；需要持续对照时才钉住。观察掀开区域是否足够阅读，钉住状态是否清楚。 |
| 重要区域透出 | 同时看到前窗文字与后窗 Figure、表格或关键句 | 优先保护前窗标题和主要阅读区域；透出范围由用户明确指定或确认，避免自动猜错重点。 |
| 边界退让 | 临时为第二篇文献或图示腾出空间 | 保持正文可读字号，不靠缩小 PDF 内容换取空间；遮挡过大时退回普通叠放。 |
| 融合与拆分 | 把正文与附录、中英文版本或引用文献作为一组移动 | 分组关系可见，可单独拆出、撤销；验证「连在一起」是否反而限制独立滚动与比较。 |
| 纵深与浏览轨迹 | 从主论文打开外部网页、引用文献后返回来源 | 记录来源与原文阅读位置；不能只靠空间深浅表达引用关系。原方案的 Space 透视需改键或取消。 |
| 胶囊与预览 | 暂收低优先级材料，给主论文留出阅读面积 | 胶囊需显示材料身份和恢复入口；手动布局变化先预览，用户确认或撤销，不出现 Agent 提案。 |

可追加论文阅读专用交互，例如「双文献对照锚点」「图文临时联排」「引用来源回跳」。加入前应说明它解决哪一个任务阻碍、比现有形式多提供了什么能力，以及如何沿用同一材质和运动语言。

## 5. 实验环境的基本行为

1. **阅读位置可靠。** 每个 PDF/网页窗口保留文档身份、页码或滚动位置；临时查看、分组、收纳及返回后可恢复。实验开始时用固定页面和窗口状态复位。
2. **操作由用户发起。** 研究的是人与窗口的交互，所有移动、透出、钉住、分组、收纳和返回都由被试触发。自动内容理解、自动匹配段落和自动布局不纳入本阶段比较。
3. **文本优先。** 任何膜、光学效果和动画都不使正文、图注、页码或引用标记难以阅读；拖动时反馈及时，完成后状态稳定。
4. **状态可理解且可撤销。** 分组、钉住、透出、纵深和胶囊有明确的当前状态、退出方式与撤销路径；来源关系不能因窗口被收纳而丢失。
5. **输入不冲突。** 暂时禁用 Space 的 Agent 唤起及相关选择/接受流程。普通阅读中的 Space 滚页行为需在实际 PDF 组件中检查；任何新快捷键都应避免抢占阅读应用的常用键。
6. **素材可复现。** 每项任务使用固定版本文件、目标页/图/段落、初始窗口布局及可检查的完成标准。外部网页优先使用已保存的本地副本，同时记录离线资源缺失或链接失效情况。

## 6. 建议的预实验比较方式

先用少量代表性任务验证交互是否适合论文阅读，再决定正式实验条件。每次只清楚界定被比较的窗口能力：例如「普通叠放 vs 掀角」「普通切换 vs 透出」「独立窗口 vs 融合分组」「传统返回 vs 来源轨迹」。材料、目标、起始布局和完成标准应保持一致，任务顺序需要平衡。

建议记录：任务完成情况与时间、窗口切换/移动次数、误操作和撤销次数、返回原文所需步骤、阅读位置丢失次数，以及被试对控制感、可读性和操作负担的主观评价。日志应记录具体交互事件与条件；不再把 Agent 接受/拒绝作为本阶段指标。

## 7. 准备顺序与待确认项

1. 核对六类任务的目标页、关键段落、图号、引用链和最终交付动作；补齐回答窗口、截图目标工作区等尚缺的实验内容。
2. 确认 PDF 与网页存档在虚拟桌面可稳定打开，页面可定位，切换后阅读位置可恢复。
3. 建立无 Agent 的论文阅读场景入口，禁用 Space 唤起和所有隐性 Agent 触发，保留普通窗口操作与研究日志。
4. 为候选交互做低保真任务走查，筛掉不能改善阅读或明显破坏可读性的形式，再做可运行原型。
5. 预实验后确定正式条件、任务顺序、指导语、训练题、完成标准与分析指标。

当前最需要研究者确认的是：正式实验要比较哪几种交互；「截图转移」的两个目标窗口是什么；AI 回答对照任务中的回答内容和目标句；中英 PDF 的段落对应点；以及是否把外部网页任务纳入同一轮实验。这些问题不阻碍环境结构和无 Agent 模式的准备。
