# 实验 App 的进入流程

填写姓名和学号 → 教学练习 → 掌握效果测试 → 正式实验入口。

姓名、学号去除首尾空格后均须非空。教学页提供中文论文、英文论文、架构图、笔记、AI 问答、网页、图库及文件夹，可随时切换交互形式。点击“进入掌握效果测试”后按题目准备独立窗口；测试页不显示操作步骤。

| 交互形式 | 操作题目标 | 通过判定 |
| --- | --- | --- |
| 掀角查看 | 保持窗口位置，读出被遮住的参考编号 | 实际执行掀角、编号正确且窗口位置不变 |
| 融合与拆分 | 融合、一起移动、再拆开 | 检测到稳定融合后的移动，再检测到分离 |
| 重要区域透出 | 覆盖参考卡片后仍可看到编号 | 标记区域包含编号，前窗覆盖编号且显示透出区域，答案正确 |
| 胶囊与提案预览 | 暂收材料，再恢复 | 检测到胶囊状态，随后完整恢复 |
| 截图停靠 | 截取架构图并停靠融合 | 练习论文产生截图，截图窗口完成与来源论文的融合；不对截图内容作语义判分 |
| 图像吸顶 | 阅读到第 4 页时保留架构图 | 论文已滚至第 4 页，吸顶图仍显示 |
| 融合后同步滚动 | 两份论文融合后联动读至第 3 页 | 融合组存在，左右阅读位置一致，并产生实际同步滚动记录 |

未通过时留在本题，可继续操作、重新布置本题，或返回练习。已通过题目保留；全部通过后才能进入论文阅读、文件管理两个入口。正式实验的题目与进度不由教学操作推进。

姓名、学号和七道题的通过结果、用时、提交次数随正式实验 JSON 一起导出。参与者信息和教学进度在当前页面会话中保留，关闭并重新打开实验 App 可继续；刷新页面会重新开始。正式实验入口函数同时校验前置流程。
