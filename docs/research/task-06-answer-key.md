# 图像问答与原文核对 · 研究者答案

被试从《Attention Is All You Need》中文版第 3 页截取图 1，作为图片发送到 AI 问答窗口。窗口返回三句固定的**实验示例回答**，不是实时模型输出。实验记录图片发送事件与选择结果；目前不会自动识别所附图片是否确为图 1。

| 示例回答 | 判断 | 依据 |
| --- | --- | --- |
| 图左侧是编码器，右侧是解码器。 | 正确 | 图 1 中左侧输入嵌入进入编码器，右侧输出嵌入进入解码器。 |
| 编码器和解码器都包含带掩码的多头注意力。 | **错误，测验答案 B** | 图 1 中带掩码的多头注意力仅位于解码器底部；编码器使用普通多头注意力。中文版第 3 页 §3.1 对解码器的遮蔽机制有说明。 |
| Linear 后接 Softmax，输出词汇概率。 | 正确 | 图 1 顶部的输出路径依次是 Linear、Softmax、Output Probabilities。 |
